Condicionales: el programa decide

Con if el programa toma un camino u otro. Mueve la nota y mira qué rama se activa.

int nota = 7;if (nota >= 9)    Console.WriteLine("Excelente");else if (nota >= 6)    Console.WriteLine("Aprobado");else    Console.WriteLine("Reprobado");
